# Evaluation

Three artefacts live here, and only one of them is automated.

| File | What it is |
|---|---|
| `golden_set.jsonl` | **Hand-labelled.** 34 questions → the line ids that answer them. |
| `results.md` | ⭐ The writeup: numbers, and what degraded and why. |
| `results.json` / `sweep.json` | Raw output, regenerated by `make eval` / `make sweep`. |

## The golden set

One JSON object per line:

```json
{
  "id": "q03",
  "question": "How many times does Vale break a promise across the six seasons?",
  "kind": "semantic",
  "character": null,
  "season": null,
  "expected_line_ids": [9, 10, 30, 37],
  "notes": "why these lines and not others"
}
```

- `kind` — `lookup` (a column holds the answer), `semantic` (only meaning finds it), or
  `empty` (the corpus cannot answer it, and saying so is the correct behaviour).
- `character` / `season` — when set, the retrieval call is scoped the same way, so every
  expected line **must** be spoken by that character / fall in that season. A test enforces
  this; a mismatch silently caps recall below 1.0 and makes the number meaningless.
- `notes` — why this labelling. This is the part that is worth re-reading in six months.

Labelling is human work and stays human work. It is the reason the numbers in `results.md`
mean anything.

## Metrics, and why there are several

- **recall@k** — of the expected lines, how many came back in the top k. Retrieval quality.
- **hit@k** — did *at least one* expected line come back. A different question, and the two
  disagree on this corpus (see `results.md` §2).
- **abstention curve** — at each distance cut-off, correct abstention on unanswerable
  questions against false abstention on answerable ones.
- **citation faithfulness** — of the lines the final answer relies on, how many were actually
  retrieved. Needs `GOOGLE_API_KEY`; run `subtext eval --with-agent`.

The split exists to separate **retrieval failure** (the answer never came back — recall@k) from
**generation failure** (it came back and the answer ignored it, or cited something that never
arrived — faithfulness). They have different fixes, and one blended "accuracy" number hides
which one you have.

## Running

```bash
make eval                                   # recall@k + abstention, line strategy
uv run subtext eval --strategy window --window-size 3
uv run subtext eval --with-agent         # adds faithfulness (uses Gemini)
make sweep                                  # line x window3 x window5, k in 1..20
```
